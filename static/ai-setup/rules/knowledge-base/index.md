> AI-written and cleaned from one person's working setup. Placeholders in angle brackets are not real values: ask your user for theirs. The newest version is at https://oneillo.com/ai-setup/rules/knowledge-base/.

Sets the rules agents follow to find, write, link, and check notes in a knowledge base kept as a vault of Markdown notes.

- **What it is:** The knowledge base's rules file is a Claude Code rules file that tells agents where to start, how to name, write, and link notes, where drafts for review go, and how history is kept.
- **How it starts:** Sessions read it before they work in the knowledge base.
- **Needs:** Obsidian, uv, and git
