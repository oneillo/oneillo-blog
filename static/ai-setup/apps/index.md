The apps around Orlando's sessions. Each one is described here, not shared as text. When an app goes public, its section links to it.

## Corillo

Lets you review AI-written documents by leaving comments on the page, then has the agent make changes and reply to each comment.

Public: [its code](https://github.com/oneillo/corillo).

## Brega

Keeps your tasks in a small Mac to-do app, and lets Claude Code sessions read, add, and finish them.

Not public yet.

## Pregón

Takes a finished blog post from your notes to your Hugo blog with one button, showing the post as the site will.

Not public yet.

## The heartbeat

Runs AI agent jobs on a Mac on a timer, starting a Claude Code session only when a free check finds work to do.

Not public yet.

Its skill has its own page: [Heartbeat](https://oneillo.com/ai-setup/skills/heartbeat/).

## Latido

Shows what the heartbeat is doing: its jobs, when they run, how each run ended, and whether anything is wrong.

Not public yet.
