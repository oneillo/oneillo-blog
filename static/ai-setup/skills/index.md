# Skills

- Address: https://oneillo.com/ai-setup/skills/
- Last updated: 2026-11-27

> AI-written and cleaned from one person's working setup. Placeholders in angle brackets are not real values: ask your user for theirs. The newest version is at https://oneillo.com/ai-setup/skills/.

The skills in Orlando's AI setup, the written routines a session can run.

A skill is a written routine. Orlando starts one with a slash, or Claude picks it up when it fits.

## Ending a session well

- [Close shop](https://oneillo.com/ai-setup/skills/close-shop/): Ends a working session in order: saves project context, checks corrections are in memory, and commits the session's changes.
- [Process feedback](https://oneillo.com/ai-setup/skills/process-feedback/): Reviews saved memories, promotes lasting lessons to the right rules file, agent, skill, or hook, and prunes the rest.
- [Save session](https://oneillo.com/ai-setup/skills/save-session/): Saves a project's goal, decisions, and next steps at the end of a session so the next session can pick up where this one left off.
- [Tune setup](https://oneillo.com/ai-setup/skills/tune-setup/): Researches current Anthropic guidance, then proposes improvements to the agents, skills, and rules of a Claude Code setup.

## Knowledge base

- [Connect](https://oneillo.com/ai-setup/skills/connect/): Links new knowledge base notes to concept notes, creates concept notes for recurring ideas, and adds cross-area links.

## Writing and publishing

- [Publish setup](https://oneillo.com/ai-setup/skills/publish-setup/): Publishes the AI Setup section of a blog: cleans private details, checks twice, builds pages, and asks before going live.

## Audio and video

- [Podcast](https://oneillo.com/ai-setup/skills/podcast/): Turns source documents into a two-host podcast MP3, writing the script and rendering the voices on the Mac.

## Working while you are away

- [Heartbeat](https://oneillo.com/ai-setup/skills/heartbeat/): Adds, changes, pauses, or removes scheduled jobs on a Mac scheduler that runs a free check first, then a capped agent session if there is work.
- [Relay](https://oneillo.com/ai-setup/skills/relay/): Runs a project's roadmap unattended as a relay of fresh Claude Code sessions, each leading one batch with parallel agents.

## From others

- [Rex](https://oneillo.com/ai-setup/skills/rex/): Manages Rex terminal sessions, tabs, and panes, runs commands in them, and reads their output.

## Other

- [Evals](https://oneillo.com/ai-setup/skills/evals/): Checks that a decided change to an agent or instruction file is no worse than the current version, using a blind panel of judges.
