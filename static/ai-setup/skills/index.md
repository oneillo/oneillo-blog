# Skills

- Kind: Claude Code skills
- Address: https://oneillo.com/ai-setup/skills/
- Last updated: 2026-11-23

> AI-written and cleaned from one person's working setup. Placeholders in angle brackets are not real values: ask your user for theirs. The newest version is at https://oneillo.com/ai-setup/skills/.

The skills in Orlando's AI setup, the written routines a session can run.

A skill is a written routine. Orlando starts one with a slash, or Claude picks it up when it fits.

## Ending a session well

- [Close shop](https://oneillo.com/ai-setup/skills/close-shop/): Ends a working session in three steps: saves project context, checks corrections are in memory, and commits the session's changes.
- [Process feedback](https://oneillo.com/ai-setup/skills/process-feedback/): Reviews saved memories, promotes lasting lessons to the right place, and prunes the rest so memory stays lean.
- [Save session](https://oneillo.com/ai-setup/skills/save-session/): Saves where a project stands in a context file so the next session can pick up where this one left off.
- [Tune setup](https://oneillo.com/ai-setup/skills/tune-setup/): Researches current Anthropic guidance, updates a guidance file, and proposes specific improvements to a Claude Code setup.

## Knowledge base

- [Connect](https://oneillo.com/ai-setup/skills/connect/): Links new knowledge base notes to concept notes, builds concept notes for recurring ideas, and adds cross-area links.

## Writing and publishing

- [Obsidian to Hugo](https://oneillo.com/ai-setup/skills/obsidian-to-hugo/): Converts an Obsidian blog post to Hugo-ready Markdown, fixes links and pictures, and places it in a review folder.
- [Publish post](https://oneillo.com/ai-setup/skills/publish-post/): Publishes a finished blog post to a Hugo site, checks the build, and pushes it to GitHub.
- [Publish prep](https://oneillo.com/ai-setup/skills/publish-prep/): Prepares a finished blog post for publishing with title options, a description, a LinkedIn blurb, and a Substack version.
- [Publish setup](https://oneillo.com/ai-setup/skills/publish-setup/): Publishes an AI setup to a blog section: gathers files, has agents remove private details, checks twice, previews, and asks before going live.

## Audio and video

- [Podcast](https://oneillo.com/ai-setup/skills/podcast/): Turns source documents into a two-host podcast-style MP3 by writing a script, then rendering it locally with a text-to-speech voice.
- [Video title cards](https://oneillo.com/ai-setup/skills/video-title-cards/): Makes intro, outro, and interstitial title cards with ffmpeg and joins them to screen recordings.

## Working while you are away

- [Heartbeat](https://oneillo.com/ai-setup/skills/heartbeat/): Adds, changes, pauses, or removes scheduled jobs on the heartbeat, a scheduler that runs a free check and then an agent session with limits.
- [Relay](https://oneillo.com/ai-setup/skills/relay/): Runs a project's roadmap unattended as a relay of fresh Claude Code sessions, each leading one batch with parallel agents and handing off to the next.

## From others

- [Rex](https://oneillo.com/ai-setup/skills/rex/): Manages Rex sessions, tabs, and panes, runs commands, and reads terminal output from the command line.
