The apps around Orlando's sessions. Each one is described here, not shared as text. When an app goes public, its section links to it.

## Corillo {#corillo}

Lets you review AI-written documents by leaving comments on the page, then has the agent make changes and reply to each comment.

Public: <a href="https://github.com/oneillo/corillo" target="_blank" rel="noopener">its code</a>.

## Brega {#brega}

Keeps your tasks in a small Mac to-do app that AI agents can read, add to, and finish from any Claude Code session.

Not public yet.

## Pregón {#pregon}

Publishes a finished post from an Obsidian vault to a blog with one button.

Not public yet.

## The heartbeat {#heartbeat}

Runs agent jobs on a timer, checks for work for free first, and starts a Claude Code session only when there is something to do.

Not public yet.

Its skill has its own page: <a href="/ai-setup/skills/heartbeat/">Heartbeat</a>.

## Latido {#latido}

Shows what the heartbeat, the helper that runs scheduled jobs on your Mac, is doing, in a small window.

Not public yet.
