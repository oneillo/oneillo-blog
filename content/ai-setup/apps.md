## Corillo {#corillo}

Corillo is a Mac app for writing documents with an AI agent. You leave comments on the draft, and the agent makes the changes and replies to each comment, much like reviewing a document with a colleague.

Public: <a href="https://github.com/oneillo/corillo" target="_blank" rel="noopener">its code</a>.

Taken out: nothing.

## Brega {#brega}

Brega is a small to-do app for the Mac that holds tasks and nothing else. You and your AI agents work on the same list, and an agent can be started on a task or hand it to another agent to do later.

Not public yet.

Taken out: 1 private project folder name.

## Pregón {#pregon}

Pregón is a small Mac app that takes a finished post from an Obsidian vault to a blog with one button.

Not public yet.

Taken out: 1 private project folder name.

## The heartbeat {#heartbeat}

The heartbeat runs agent jobs on a computer on a timer. Every 30 minutes, while the computer is awake, it checks which jobs are due, runs a free check to see if there is any work, and only then starts a Claude Code session, logging the cost and sending a notification when there is something to see.

Not public yet.

Its skill has its own page: <a href="/ai-setup/skills/heartbeat/">Heartbeat</a>.

Taken out: 1 project folder name.

## Latido {#latido}

A small Mac app that shows what the heartbeat is doing. The heartbeat is the helper on a Mac that runs jobs on a schedule, and Latido is its window.

Not public yet.

Taken out: 1 private project folder name.
