A custom agent is a role a session can take on. Each one has three parts: a role prompt, its own memory, and the knowledge base for the facts about Orlando. The prompt is the part worth borrowing, so it is shared here, cleaned. Each agent's memory is never read.

- <a href="/ai-setup/agents/writer/">Writer</a>: A custom agent that acts as a writing partner for a blog, newsletter, and LinkedIn posts.
- <a href="/ai-setup/agents/trainer/">Trainer</a>: A prompt for a strength coach agent that builds training blocks for a home gym, checks the client's training log before programming, and delivers programs as spreadsheet files.
- <a href="/ai-setup/agents/financial-advisor/">Financial advisor</a>: A custom agent for the household's money decisions, with its details left out of this section on purpose.
